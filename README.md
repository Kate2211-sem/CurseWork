# Курсовой проект: Веб-сайт салона красоты "OK!"

Этот проект представляет собой веб-приложение для салона красоты с функционалом магазина косметики, корзиной заказов и системой управления.

## 🛠 Функционал
- **Каталог:** Удобный каталог с многоуровневой фильтрацией (по категориям, брендам и диапазону цен).
- **Поиск:** Интерактивный поиск товаров по названию с мгновенной выдачей результатов.
- **Корзина:** Управление покупками: добавление, изменение количества и удаление позиций.
- **Избранное:** Система сохранения товаров «в желаемое» для быстрого доступа.
- **Авторизация:** Безопасный вход, регистрация и разделение прав доступа (пользователь / администратор).
- **Уведомления:** Система всплывающих Toast-уведомлений о статусах действий (добавление в корзину/избранное).
- **Адаптивность:** Полная поддержка мобильных и планшетных устройств..

## 🏗 Технологический стек
- HTML5, CSS3 (использование CSS-переменных и адаптивной верстки).
- JavaScript (ES6+, работа с API, JSON Server).
- GitHub Pages для деплоя.
